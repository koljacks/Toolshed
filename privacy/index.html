Privacy policy

This policy explains exactly what happens to your data when you use Toolshed. It is deliberately specific rather than vague.

Your files

For the large majority of tools here, files you open are processed entirely by JavaScript running inside your own browser. They are never uploaded, never transmitted, and never seen by any server. Closing the tab discards them.

Nine tools are exceptions, because the work is impossible in a browser: DOCX to PDF, Word to PDF, PPTX to PDF, ODF to PDF, XPS to PDF, MOBI to PDF, Protect PDF, Unlock PDF and URL to PDF. These upload your file to a conversion server. Each of these tools displays a clear notice before you use it. On that server the file is written to a temporary folder, converted, returned to you, and the folder is deleted immediately. Nothing is retained, logged or backed up.

What is stored on your device

The site uses your browser's local storage — data that stays on your machine and is never sent anywhere — to remember:

  • which tools you have starred
  • which tools you used recently
  • whether you prefer light or dark mode
  • the conversion server address, if you set one

Clearing your browser data removes all of it.

Analytics

This site runs no analytics scripts and sets no tracking cookies of its own.

Third parties

Some tools load open-source libraries from public CDNs (cdnjs and jsDelivr) at the moment you open them. Doing so reveals your IP address to those CDNs, as with any website that loads external resources. No file data is shared with them.

Fonts are loaded from Google Fonts, which likewise receives your IP address.

If advertising is enabled on this site in future, this section will be updated to name the ad network and describe the cookies it sets, before any ads appear.

Children

This site is a general-purpose utility and is not directed at children under 13. It collects no personal information from anyone.

Your rights

Because no personal data is collected or stored on any server, there is nothing to request, export or delete. Data held in your own browser is under your control at all times.
